# Lack of Features

### Search Bar Missing in Brands and Categories

The **Brands** and **Categories** sections do not have a search bar:

- `/admin/catalogue?tab=brands`
- `/admin/catalogue?tab=categories`

Because there is no search functionality, admin cannot quickly search and verify whether a specific **brand or category already exists**.

**Expected:**  
Add a search bar to both the **Brands** and **Categories** tabs so users can easily find existing records and avoid duplicate entries.
